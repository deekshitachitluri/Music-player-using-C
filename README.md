\# C PULSE



A console-based music player developed in C, demonstrating the implementation of core Data Structures through a real-world application.





\## Features



\-  Play MP3 songs

\-  Playlist Management

\-  Favorites Playlist

\-  Queue Management

\-  Recently Played Stack

\-  Shuffle Mode

\-  Repeat Mode

\-  Search Songs

\-  Song Recommendation

\-  Most Played Analytics

\-  Colorful Console UI

\-  Pause / Resume Playback

\-  Playback Progress Bar





\##  Technologies Used



\- C Programming

\- Windows MCI API

\- Code::Blocks

\- Git \& GitHub





\##  Data Structures Implemented



\- Doubly Linked List

\- Stack

\- Queue

\- Arrays

\- Fisher–Yates Shuffle Algorithm

\- Selection Sort

\##  How to Run



1\. Clone the repository



```

git clone https://github.com/deekshitachitluri/Music-player-using-C.git

```



2\. Open the project in Code::Blocks.



3\. Build and Run.



4\. Place your MP3 files inside the `songs` folder.
